# Unnati App

## Overview

Unnati App is a Role-Based Access Control (RBAC) platform designed to digitize volunteer management and student engagement within an organization.

The application provides separate dashboards for **Students**, **Volunteers**, and **Admins**, ensuring that every user can access only the features relevant to their role.

The Admin manages the entire system through a dedicated admin panel, where volunteers can be assigned specific roles and responsibilities. Based on these assignments, volunteers can manage student attendance, upload educational resources, resolve doubts, share assignments and quizzes, and support students throughout their learning journey.

Students can access study materials, assignments, quizzes, attendance records, and raise doubts directly through the application.

By bringing all these activities into a single platform, Unnati improves communication, enhances transparency, and streamlines the management of educational and volunteer-driven programs.

---

## User Roles

The platform supports three different user profiles:

- 🎓 Student
- 🤝 Volunteer
- 👨‍💼 Admin

Each role has different permissions and responsibilities.

---

# 🎓 Student Module

## Overview

The Student Profile provides a centralized learning platform where students can access:

- Study Materials
- Assignments
- Quizzes
- Assessments
- Video Lectures

Students can also communicate directly with volunteers through the doubt resolution system.

---

## Features

### 1. Student Login

Students can securely log in using their academic information such as:

- School Details
- Class Information

---

### 2. Home Dashboard

The dashboard serves as the central hub for students and provides:

- Recommended educational videos
- Learning resources
- Quick access to study content

---

### 3. Resources

Students can access:

- Class-wise study materials
- Syllabus-based notes
- PDFs
- Educational resources

All content is organized according to the curriculum.

---

### 4. My Downloads

Students can download resources for offline use.

The My Downloads section allows students to:

- View downloaded content
- Access resources offline
- Manage study materials from one place

---

### 5. Doubt Resolution

Students can raise doubts whenever they face difficulties.

Features include:

- Ask academic questions
- Receive responses from volunteers
- Continuous learning support

---

# 🤝 Volunteer Module

## Overview

The Volunteer Profile enables volunteers to support and manage student activities through role-based permissions assigned by the Admin.

Depending on assigned permissions, volunteers can:

- Manage attendance
- Upload learning resources
- Resolve student doubts
- Track personal attendance
- Support educational activities

---

## Features

### 1. Volunteer Registration & Login

Volunteers can:

- Create an account
- Login securely
- Receive a default Volunteer role

Admins can later assign additional responsibilities and permissions.

---

### 2. Role-Based Permissions

The volunteer module follows a strict RBAC model.

Volunteers can access only those features for which they have been granted permission by the Admin.

Examples:

- Attendance Management
- Resource Management
- Doubt Resolution

---

### 3. Attendance Management

Authorized volunteers can:

- Mark attendance
- Manage attendance records
- Track volunteer participation

All volunteers can access:

- My Attendance
- Monthly attendance summaries
- Personal attendance history

---

### 4. Resource Management

Volunteers with resource permissions can:

- Upload resources
- Edit resources
- Delete resources
- Manage assignments and notes

Volunteers without permission can still view available resources.

---

### 5. Doubt Resolution

Authorized volunteers can:

- View student doubts
- Respond to queries
- Provide academic guidance

This helps maintain effective communication between students and volunteers.

---

# 👨‍💼 Admin Module

## Overview

The Admin Profile serves as the central control panel of the platform.

Administrators are responsible for:

- User management
- Volunteer management
- Role assignment
- Permission control
- System monitoring

---

## Features

### 1. Admin Login

Administrators can securely access the dedicated admin dashboard.

---

### 2. User Management

Admins can:

- View all registered users
- Monitor user information
- Manage user accounts

User details include:

- Name
- Contact Information
- Assigned Role
- Other profile information

---

### 3. Role Management

The primary responsibility of the Admin is managing permissions.

Admins can:

- Assign roles
- Update permissions
- Modify responsibilities

This ensures volunteers only access features relevant to their duties.

---

### 4. Volunteer Management

Administrators can:

- Monitor volunteer activities
- Manage volunteer accounts
- Oversee assigned responsibilities

---

### 5. Complete System Access

Administrators have full access to:

- Student Module
- Volunteer Module
- Admin Module

This enables centralized control and management of the entire platform.
